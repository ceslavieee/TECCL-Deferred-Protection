# Frozen InterDC8 holdout figure

The files in this directory are generated by
`teccl/examples/plot_dynamic_admission_holdout.py` from all 16 raw seed-level
reports (`20260812`--`20260827`). The generator independently checks the stored
combined summary, the frozen implementation fingerprint, every policy ledger,
and every accepted request's schedule audit and failure-time certificate before
exporting the table or figure.

The figure's claim is intentionally narrow: at the selected InterDC8 transition
load (`lambda=0.06` arrivals per epoch), DDPP produced more certified admissions
on 12 paired seeds, tied on four, and lost on none. The aggregate early-DPP
blocking probability is `15.625%`; DDPP is shown as the honest interval
`3.125%`--`3.90625%` because one solver outcome is unknown. This is final
held-out evidence for the selected load, not a complete multi-load performance
curve.

Regenerate with:

```bash
MPLCONFIGDIR=/tmp/teccl_matplotlib \
  /opt/miniconda3/envs/teccl_env/bin/python \
  teccl/examples/plot_dynamic_admission_holdout.py
```
